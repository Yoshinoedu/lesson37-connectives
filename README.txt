Lesson 37 接続詞①

使い方：index.html を開くと学習できます。インストール不要です。
筆記は英文の文字入力で判定します。手書きの文字認識は端末のキーボード機能をご利用ください。
最初の筆記正解で即クリア。不正解なら日本語の語順説明→並べ替え→穴埋め→再筆記。
筆記は合計5回まで。5回不正解なら答えを表示し「要復習」として保存します。
大文字・小文字・句読点・一般的な短縮形と登録済み別解を許容します。
進捗は同じ端末・同じブラウザー・同じURLに保存されます。プライベートブラウズ等では保存できないことがあります。
読み上げはOSの英語音声に依存します。最初のタップ後に音が使えます。

GitHub Pagesで公開する方法：
1. ZIPを展開し、index.html、style.css、app.js、.nojekyllをリポジトリの直下へアップロード。
2. リポジトリの Settings → Pages → Deploy from a branch を選択。
3. main ブランチ / (root) を選んで Save。
4. 表示された公開URLをPC、iPad、Androidのブラウザーで開く。

教材について：
ユーザー提供のLesson 37 p.80–81の要約と例文を基準に作成。
整序・Writeは提供された例文を使用。一部の選択問題は同範囲の補充例です。
教科書画像自体との照合は未実施です。
問題の変更は app.js の add(...) 部分で行えます。
