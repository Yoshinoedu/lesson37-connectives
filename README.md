# Lesson 37 接続詞① — GitHub Pages公開用

最新版：都立AIへの質問コピー、応用6問、筆記の複数解答・短縮形対応、基本語彙と単語メモ入り。
画面にYoshilingoの表記はありません。合言葉は **1231**（全角・前後の空白も対応）。

## アップロード

1. ZIPをダウンロードし、右クリック「すべて展開」。
2. GitHubの公開先リポジトリで「Add file → Upload files」。
3. 展開した **6つのファイル全部** をアップロード。ZIPそのものや外側のフォルダーを置かないでください。
4. Commit changesで保存。
5. Settings → Pagesで、Deploy from a branch、main、/(root)を選んでSave。
6. Pages画面に表示される公開URLを開きます。反映には数分かかる場合があります。

既存のL37を更新する場合は同じ場所に上書きします。index.htmlがリポジトリ直下にあることを確認してください。キャラ画像・CSS・問題・JavaScriptはindex.htmlにすべて埋め込み済みなので、assetsフォルダーは不要です。

## 同梱ファイル

- index.html：アプリ本体（画像・問題も内蔵）
- manifest.webmanifest：ホーム画面追加用設定
- sw.js：オフラインキャッシュ
- icon-192.png / icon-512.png：アイコン
- README.md：この説明

APIキー・ビルド作業は不要。合言葉は簡易ゲートで、本格的なアクセス制限ではありません。

## 学習仕様

導入3画面 → 18個のミニ項目 → FINAL 15問。応用6問は任意です。
初回筆記をヒントなしで一発正解すると即クリア。誤答時は英語順の日本語 → チャンク並べ替え → 穴埋め → 再筆記。筆記は初回を含め最大5回、失敗後は見本を確認して進めます。選択肢は出題ごとにシャッフルします（偶然同じ順番になることはあります）。

筆記は狙った文法と意味を満たす登録済み別解、短縮形、大文字小文字、句読点の違いに対応します。すべての自由な英文をAI採点する方式ではありません。文法の条件が指定された問題では、その条件を満たす必要があります。

「都立AIに聞く」を開き、質問文をコピー → 都立AIを別タブで開く → 貼り付けて送信。自動送信やAPI接続はありません。コピーできない環境では表示された文章を手動コピーしてください。都立AIの利用条件・ログインが必要な場合はそちらに従ってください。通常学習でAI欄を開いた項目はヒント使用扱いになり、即クリアにはなりません。FINAL・応用では回答確認後に質問欄が表示されます。

18項目とFINALを完了すると1周。「次の周をはじめる」で進み、3周でヨシどんぐりを解放します。見本確認で終えた項目も完了に含みます。実力は最後のPAPER TEST案内に従い、紙で確認してください。紙の問題は同梱していません。

## 保存・端末

完了項目、周回数、キャラ、音、訪問日を同じ端末・ブラウザのlocalStorageに保存します。同日訪問は日本時間で1回。途中の入力は保存されません。別端末への同期はありません。更新時に公開元を変えず、ブラウザの保存データを消さなければ既存の記録を利用できます。

PC・スマホ・タブレット向けレスポンシブ表示。音声は端末の読み上げ機能を利用します。音声の有無・声・オフライン利用は端末に依存します。初回オンライン読み込み後にアプリのオフラインキャッシュを作りますが、都立AIにはネット接続が必要です。端末によるキャッシュ削除後は再読み込みしてください。

## 更新・確認

画面が古い場合はオンラインで再読み込みしてください。次回ファイルを変更したときはsw.jsのバージョン文字列も更新します。
